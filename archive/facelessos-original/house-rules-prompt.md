# The old house-rules prompt (retired)

Pasted at the start of every script chat before the rebuild. Kept for comparison only. Its rules now live in `core/workflow.md`, `core/cta-and-endings.md`, `core/offer-rules.md` and `core/claims-policy.md`. Summary of its sections:

- **Intake (nine questions):** script type (Talking Head or Classic), title, talking points or reference script, target length in minutes, format, niche, the channel block (CHANNEL PERSONA + CTA RULES), the last five rotation log lines, and voice provider (ElevenLabs or Minimax).
- **Confirm the type and voice** before writing.
- **Output skeleton:** SCRIPT TYPE line, the script, a compact verdict (VERDICT + HOUSE FORMAT line, every audit silent), the ROTATION LOG ENTRY, and the VO copy (ElevenLabs) or "VO COPY: not required (Minimax voice)."
- **Two script types:** Classic (CTAs inline) and Talking Head (CTAs wrapped in ===START CTA(Printed Book Title)=== / ===END CTA=== markers, each alone on its line, exactly two blocks; NO BOOK variant).
- **Placement:**
  - the cold open reaches value fast, with the persona intro capped at 2-3 sentences
  - the mid-CTA never comes before the first delivered value and is placed by structure, not the clock
  - an open loop sits right before the mid-CTA
- **Mid-CTA formula (120-160 words):**
  - seam entry and provenance
  - contents inventory (true counts only)
  - contextual utility
  - action choreography (camera, QR code, description link)
  - a no-rush close
  - no subscribe ask
- **End-CTA:**
  - directly after the final content sentence
  - book pitch, compressed choreography, then one subscribe sentence (70-120 words)
  - exactly one closing sentence after it, the last line of the script
  - no recap
- **Claims policy:**
  - no fabricated verifiable biography (ages, relatives, heritage, years of experience, lived or authored claims)
  - zero health claims or guarantees
  - no prices or price anchors for the book
  - no manufactured urgency or false intimacy
  - no negative claims about named companies
  - the book identified as a digital book
  - book facts only from the CTA RULES block
  - safety guidance kept inside the script
- **CTA variation:**
  - every quoted phrasing is register-only
  - log openings banned from reuse
  - banned echoes: "before we start counting…", "take your time / there is no rush / I'll wait right here / I'll be here", "open your camera, the same one you use to take pictures", "square code", "the link is waiting for you", "it deserved to be written down"
- **VO copy (ElevenLabs v4):**
  - identical text with light tags (about 1 per 80-120 words)
  - allowed tags only: [warm] [thoughtful] [quietly] [matter-of-fact] [slightly amused] [chuckles] [sighs] [short pause] [long pause] [slower] [emphatic]
  - markers reproduced untagged
  - a strip-tags identity check
