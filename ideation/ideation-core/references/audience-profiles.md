# Audience Profiles — thin, invariants only

A profile holds only what is true of the viewer **regardless of niche**: values, tone limits, universal caps words, and audience-tab vocabulary finds. How the viewer shows up in a niche — mode, lever ranking, dead levers, money/time language, adversaries — stays in the overlay's `audience.md`. A profile never defines a niche.

**Promotion rule (operator call, 2026-09-06).** A word or lever enters a profile as `proven` once it has won on **two channels** serving that audience — any niches; two channels inside one niche count. Until then it is `candidate` (from an audience-tab find or a single channel's data) — usable, but labeled. Words proven for **both** profiles go to the cross-audience universal list (below).

**Split test (empirical).** Two channels share a profile when their audience tabs show the same adjacent channels. If file evidence ever contradicts a split below, flag it and ask; do not silently merge or split.
