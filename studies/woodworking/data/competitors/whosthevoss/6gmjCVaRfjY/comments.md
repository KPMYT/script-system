2. (913 likes) Protip from a housewife who crafts a lot. If you're using wax often, buy the cheapest crock pot you can find. Check the thrift stores first. This is your dedicated wax pot. If you plan to make something like this, set it to low, then forget about it overnight. I've got a wax pot that's always on because it comes up often. Dip out what you need, make your mix, and move on with your life. No melting. No fiddling. No waiting. If you plan on waiting to save up sawdust for a big batch later, just turn it off and forget it exists until you're ready for it. You can turn it on high for an hour to hurry things along if you need to, but don't leave it like that. Remember, these pots are built to be set up and left alone for a loooong time. They can handle it.
