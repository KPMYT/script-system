# Plumbing price research (2026-10-21)

The evidence behind `plumbing-scripts/references/price-guide.md`. Collected for the operator's request (2026-10-21): "do some research on plumbing costs for all basic jobs and more intense jobs and add them to niche pack ... have agents checking each one and double checking with other agents from other sources".

## How it was done

1. **Job lists** (`A-jobs.md` to `E-jobs.md`): about 140 jobs, parts and facts, drawn from Roger's and Mark's book fix indexes, the model library's topics and the first plumbing test brief.
2. **First pass** (`A-research.md` to `D-research.md`): one researcher per group, two or more independent publishers or retailers per figure, each source with its URL, figure and year, tagged "read on page" or "via search summary". A shared web-search limit stopped groups A, C and D early; `E-research.md` filled the gaps.
3. **Second pass** (`A-verify.md`, `B-verify.md`, `CE-verify.md`, `D-verify.md`): a different researcher per group checked every figure against publishers the first researcher didn't use, with a verdict (confirmed, adjust, disputed, unverified), a suggested script range, live spot-checks of figures first seen only in search summaries, and flags for old or easy-to-dispute figures.
4. **The guide** takes each verifier's suggested range. Disputed or single-source pro prices became "in words" lines.

## Limits

- HomeGuide, Angi/HomeAdvisor, Forbes and some retailers block direct page reads, so their figures were seen only in search summaries. They're used as estimates, never as named sources.
- Angi and HomeAdvisor are one company; This Old House and Today's Homeowner share a cost table; True Value and Do it Best share listings. The verifiers counted each pair as one source.
- Prices are October 2026 national figures. Re-check yearly.

Collect and describe only: these files are not edited to fit a conclusion (`CLAUDE.md`).
